# 📌 Sistema de Reportes UTI

## 🧾 Descripción del Proyecto

El proyecto consiste en el desarrollo de un **sistema web de gestión de reportes documentales** para la **Unidad de Tecnologías de Información de la Facultad de Ciencias Económicas (UTI-FCE)**.

El sistema permitirá **digitalizar, almacenar y gestionar documentos de docentes**, principalmente resoluciones de asignación de materias en formato PDF, reemplazando el proceso manual y físico actual que genera cuellos de botella y demoras.

El sistema contempla tres roles principales:

* 👨‍💼 **Administrador**
* 🧑‍💻 **UTI**
* 🗂️ **Secretaría**

Cada uno contará con distintos niveles de acceso para:

* Carga de documentos
* Consulta de información docente
* Generación de reportes básicos y avanzados

El sistema será accesible desde cualquier dispositivo con conexión a internet.
